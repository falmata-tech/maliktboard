# Feature Specifications

Create one Markdown file per affected layer using `specs/templates/FEATURE_SPEC_TEMPLATE.md` and IDs such as `FE-001`, `BE-001`, and `DEP-001`. Cross-link layer specs for one outcome. Do not reuse IDs or delete accepted history; supersede it.

The active spec is a scope boundary. New findings become proposed linked specs unless they prevent satisfying an accepted criterion.
